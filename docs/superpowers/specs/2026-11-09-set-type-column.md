# Set type column

The user wants set type to be a prominent, separate column with a real button, a basic default and alternatives such as warm-up, working and drop sets. New rows default to Regular. Use four stored types: Regular, Warm-up, Working set and Drop set. Do not reclassify existing saved working/warm-up or missing legacy values.

The type button opens a native choice sheet with a checkmark and short definitions. Choosing a type saves immediately; a storage failure retains the old persisted selection and offers Retry. Preserve raw numeric input, focus, canonical precision, dates, set identity, annotations and automatic saving. Keep Reps left in a separate control. Normal phone layouts show a Type column; compact/Larger Text layouts stack clearly labeled controls rather than squeezing values or targets.

Regular is the ordinary default set; Working set is an explicitly marked target set. Both count toward the working-set plan. Warm-ups and Drop sets remain in history and total volume/counts but do not count toward that target. A workout containing Drop sets cannot qualify for automatic load-increase guidance, including when it is the latest drop-only session. This is a conservative app comparison rule, not a claim about training effectiveness.

Extend enum metadata with regular and dropSet while retaining existing raw values. Write local format 6 and full-backup version 3; read older supported formats without rewriting on open. Restore and CSV preserve type values. Keep the established palette, Georgia headings, flat lists, selected accessibility traits and 44-point targets; no decorative left bars.
