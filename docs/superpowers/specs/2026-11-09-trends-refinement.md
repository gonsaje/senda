# Trends refinement

The user requested Trends to feel as clean and intuitive as the refined week and workout screens, retaining ivory, terracotta, charcoal and the Georgia notebook headings.

Keep exercise comparisons as the primary content. Put History and the existing Records disclosure beside the title, with adaptive stacking before labels become crowded. Expanded records have a visible All-time records heading and appear above the range selector, making their scope explicit. Preserve the existing PR/history destinations and workout return context.

Name the comparison section Top-set comparisons once, then label source values Latest and Previous with full dates. Accessibility keeps the full top-set wording. Reduce ordinary comparison row spacing/padding slightly while preserving numeric size, 44-point minimum buttons and intrinsic Larger Text growth. Keep milestones, period totals, this-week counts and training rhythm in their existing relative order below comparisons. Clip scrolling content to its layout bounds so it does not overlap status-bar text.

The alternatives were spacing alone, which leaves records hard to find, or moving totals above comparisons, which reverses the established comparison-first priority. The chosen refinement makes existing navigation discoverable and reduces repeated labels. Range selection, calculations, feedback semantics, empty states, record values and persistence remain intact. Native review showed the shared period control breaking the selected weeks label at the largest text size; its two buttons stack vertically at accessibility sizes in both Trends and exercise history, retaining their existing selection behavior, colors and minimum targets.

Verify native iPhone 16 and compact iPhone navigation, default and Larger Text headers, and rendered mixed-change/bodyweight/kilogram/one-day/old-history/empty states. Preserve unrelated work. No commits or pushes.
